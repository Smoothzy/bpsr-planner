# 📦 Files to Upload to GitHub

When uploading to GitHub, include these files:

## ✅ REQUIRED Files (Must upload):
1. **index.html** - Main planner page
2. **players-overview.html** - Player statistics page
3. **raid-finder.html** - Advanced raid finder page
4. **styles.css** - Main stylesheet
5. **dark-mode.css** - Theme and colors
6. **script.js** - Core JavaScript logic
7. **README.md** - Project documentation
8. **.gitignore** - Git ignore rules

## ❌ DO NOT Upload (excluded by .gitignore):
- debug.html (development tool)
- test_timezone.html (development tool)

## 📚 Optional Documentation (helpful but not required):
- DEPLOY.md (deployment guide - helpful for contributors)
- QUICKSTART.md (this file - helper for you)

## 🚀 Quick Upload Steps

1. Go to https://github.com/new
2. Create repository named: `bpsr-planner`
3. Make it **Public**
4. Don't initialize with README
5. Click "uploading an existing file"
6. Drag the 8 required files
7. Commit with message: "Initial commit - Moonlight Raid Planner"
8. Go to Settings → Pages
9. Select branch: main, folder: / (root)
10. Save and wait 2 minutes
11. Your site is live at: `https://YOUR-USERNAME.github.io/bpsr-planner/`

---

**That's it!** Your raid planner will be live and ready to use! 🎉
